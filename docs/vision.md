# 願景

## 一句話

一個能記錄食譜，並把食譜編排成自己的餐廳菜單、以獨特的 UI 與動畫瀏覽與編輯的個人工具。

## 使用者

只有我自己，在自己的電腦上使用。

## 目標（依優先順序）

1. 食譜記錄：新增、編輯、詳情（用量、步驟、參考連結、圖片）。
2. 菜單：進入網站直接看到可編輯、可加圖片的菜單；點品項進入製作流程。獨特的 UI 與動畫是網站的必要特色，不侷限於特定形式。
3. 次要：菜單輸出 PDF、多種菜單主題。
4. 次要的次要：跨裝置使用。

## 非目標（目前）

- 社群分享、公開發佈
- 訂位、點餐、付款
- 多人協作與帳號系統
- 排程；LLM 以外的外部 API 整合（食譜匯入使用 Claude API，見 [資料來源](data-sources.md)）
- 書本式翻頁（改以獨特的 UI 與動畫為特色，見 [ADR-0007](adr/0007-paper-stack-layout.md)）
- 食材的購買紀錄、平均價與購買地點（每個食材只記一個價格，見 [ADR-0031](adr/0031-unit-conversion-data.md)）

## 設計取向

- 食譜與菜單是兩個概念：食譜是功能性資料，菜單是展示層，兩者多對多。
- 獨特的 UI 與動畫是必要特色，但資料與呈現分離，必要時保留精簡的快速檢視。
