# 願景

## 一句話

一個能記錄食譜，並把食譜編排成自己的餐廳菜單、用翻頁方式瀏覽與編輯的個人工具。

## 使用者

只有我自己，在自己的電腦上使用。

## 目標（依優先順序）

1. 食譜記錄：新增、編輯、詳情（用量、步驟、參考連結、圖片）。
2. 翻頁菜單：進入網站直接看到一本可翻閱、可編輯、可加圖片的菜單；點品項進入製作流程。翻頁是必要特色，不可砍。
3. 次要：菜單輸出 PDF、多種菜單主題。
4. 次要的次要：跨裝置使用。

## 非目標（目前）

- 社群分享、公開發佈
- 訂位、點餐、付款
- 多人協作與帳號系統
- 外部 API 整合、排程

## 設計取向

- 食譜與菜單是兩個概念：食譜是功能性資料，菜單是展示層，兩者多對多。
- 翻頁是必要特色，但資料與呈現分離，並保留不翻頁的快速檢視。
