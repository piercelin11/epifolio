# ADR-0015：步驟文字分段，以用量行 id 引用用量

日期：2026-10-12
狀態：Accepted

## 背景

之後希望步驟中提到的食材可以互動顯示用量（#54），例如步驟寫「garlic」時顯示「3 cloves」並跟著份數換算。步驟文字原本是純字串，程式不知道哪個詞指的是哪一行用量。用量行原本也沒有自己的 id，是用群組與行的索引識別（勾選狀態就用這個 key）。

## 決策

- 每一行用量（`RecipeIngredient`）有自己的 id。
- 步驟文字存成片段陣列，片段可以用 `lineId` 引用同一道食譜的用量行：`[{ text: "Put the oil, " }, { text: "garlic", lineId }, …]`；做法與菜單描述片段（`DescriptionPart`）相同，每種語言各一組（見 ADR-0013）。
- 引用的是用量行，不是食材目錄（`Ingredient`）：用量屬於那一行，同一種食材在一道食譜可能出現在不同行。
- 片段存在 JSON 內，沒有資料庫外鍵；引用的用量行不存在時，片段當一般文字顯示。
- 步驟的重點（`title`）改為選填。

## 考慮過的替代方案

- 在字串中嵌入標記（`"Put the oil, {{line:abc}} and …"`）：欄位維持字串，但要另寫解析，且標記文字在缺翻譯或解析失敗時會直接露出。
- 片段引用食材目錄的 `ingredientId`：同一食材有多行時無法判斷是哪一行的用量。
- 另建 `StepMention` 關聯表、帶外鍵：刪除用量行時資料庫會擋住或連帶處理，但要記錄每個詞在文字中的位置，且兩種語言位置不同，過於複雜。

## 後果

- 勾選狀態的 key 改用用量行 id，不再依賴順序。
- 編輯食譜時刪除用量行，要提醒或清掉引用它的片段；目前沒有編輯功能，先以「當一般文字顯示」處理。
- 「只用一半」等部分用量不在這個結構內，需要時另議。
