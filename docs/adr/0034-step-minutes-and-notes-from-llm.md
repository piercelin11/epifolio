# ADR-0034：步驟時間與重點由 LLM 匯入時產生，提醒存食譜筆記

日期：2026-10-20
狀態：Accepted

## 背景

做法紙要在每一步顯示重點與料理時間。`Step` 已有 `title` 與 `minutes` 欄位，但匯入時 LLM 只在「有幫助時」給重點，沒有時間；原文的提醒被做成最後一步的 Tip（PLAN-010 暫時的做法），而 `Recipe.notes` 一直沒有用到。時間可以由 LLM 判斷，也可以由程式從文字中的數字與時間單位推算。

## 決策

- LLM 輸出每一步的 `minutes`：只在文字明確寫出時長時填，範圍取上限、多段加總，頻率（每 3-5 分鐘攪拌）與「炒到金黃」這類沒有時長的不填；其餘為 null。存進 `Step.minutes`。
- prompt 改成每一步都要給重點（祈使語氣，幾個字）。
- 原文的提醒輸出為食譜筆記，存進 `Recipe.notes`，不再做成步驟。
- 草稿（`RecipeDraft`）帶著步驟時間與筆記，經過食譜編輯卡存檔後保留；編輯卡目前不能修改它們（#58）。

## 考慮過的替代方案

- 程式解析文字中的數字與時間單位：不花錢、結果穩定，但分不出時長與頻率，中文寫法（半小時、一個半小時、兩分鐘）與範圍、多段時間的規則難以寫完整，中英文還可能算出不同的數字。
- 顯示時才解析、不存資料庫：每次顯示都要算，也無法手動修正。

## 後果

- LLM 輸出多一個欄位，成本增加可忽略。
- 時間的正確性取決於模型；之後在編輯卡提供修改（#58）。
- 舊資料不會自動補上，PLAN-011 一次手動補齊。
