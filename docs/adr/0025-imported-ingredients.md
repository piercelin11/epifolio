# ADR-0025：匯入的新食材在食譜存檔時寫入，營養標記為估計值

日期：2026-10-13
狀態：Accepted

## 背景

匯入時 LLM 會把每個用量對應到食材目錄（ADR-0011），對不上的建議新增，並可估計每 100 g 的營養。這些決定在食材卡由使用者確認，但使用者之後仍可能在食譜卡取消。LLM 估計的營養約有一兩成誤差，之後（#42）可能要以實際資料取代。

## 決策

- 新食材與新別名不在食材卡寫入，而是隨新食譜的 Save，在同一個 transaction 中建立；取消就什麼都不寫。
- `Ingredient` 新增 `nutritionEstimated`（布林，預設 false）。LLM 預填營養時為 true；使用者在食材卡改過任一營養數字時為 false。

## 考慮過的替代方案

- 食材卡按 Next 就寫入：之後的流程較簡單，但取消時會在共用的目錄留下沒用到的食材。
- 不區分估計值：少一個欄位，但之後無法分辨哪些營養需要確認。
- 以來源字串取代布林（例如 `"llm"`、`"manual"`）：可記錄更多來源，目前只需要分兩種。

## 後果

- 草稿要能表達「待建立的食材」，用量行以暫時 key 指向它；存檔時先建食材再建用量行。
- 一次 migration（`add_nutrition_estimated`）。
- 食材卡片顯示營養時（#42）可標示估計值。
