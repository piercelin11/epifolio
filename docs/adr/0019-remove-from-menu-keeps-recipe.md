# ADR-0019：從菜單移除品項時保留食譜

日期：2026-10-13
狀態：Accepted

## 背景

菜單編輯卡可以移除品項。使用者原本希望連同食譜一起刪除，但同一份食譜可能被多個品項引用（目前沒有菜色的書就借用 Main 的食譜當佔位內容），直接刪食譜會讓其他書的品項一起消失。

## 決策

- 移除品項只刪 `MenuItem`，`Recipe` 留在資料庫；移除章節時同樣只刪章節與其品項。
- 從資料庫刪除食譜、處理「沒有被任何品項引用的食譜」，留給食譜庫（#57）一起處理。

## 考慮過的替代方案

- 刪品項時連同食譜刪除：最直覺，但會連帶刪掉其他書引用同一份食譜的品項。
- 只在食譜沒有其他引用時一起刪除：行為依情況不同，使用者難以預期；也沒有地方能找回誤刪的食譜。

## 後果

- 食譜庫完成前，被移出菜單的食譜在畫面上看不到，但資料仍在。
- `MenuItem.recipe` 維持 `onDelete: Restrict`。
