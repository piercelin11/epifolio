# 詞彙表

文件與討論一律使用這裡的中文詞；程式碼一律使用對應的英文識別字。新增詞彙時保持「一詞一定義」。

| 中文     | 英文識別字      | 定義                                                                                   |
| -------- | --------------- | -------------------------------------------------------------------------------------- |
| 食譜     | `Recipe`        | 一道菜的完整製作資料，包含用量、步驟、參考連結、圖片。功能性資料。                     |
| 菜單     | `Menu`          | 一本可翻閱的展示冊，由章節與品項組成。展示層。                                         |
| 章節     | `Section`       | 菜單中的分區（例如前菜、主菜、甜點）。                                                 |
| 品項     | `MenuItem`      | 菜單上的一道菜。引用一份食譜，並可有自己的顯示名稱、描述、價格。                       |
| 用量     | `Ingredient`    | 食譜中的一項材料及其份量與單位。                                                       |
| 步驟     | `Step`          | 食譜中的一個製作步驟，有順序。                                                         |
| 參考連結 | `ReferenceLink` | 食譜的出處或參考資料連結（ref）。                                                      |
| 翻頁檢視 | `FlipView`      | 菜單的書本式翻頁呈現。                                                                 |
| 快速檢視 | `QuickView`     | 不翻頁的清單或搜尋式呈現。                                                             |
| 菜單主題 | `MenuTheme`     | 一組菜單外觀設定（顏色、字型、頁面樣式），用於菜單呈現與 PDF 輸出。                    |
| 色彩模式 | `ColorMode`     | 整個網站介面的 light / dark / system 切換（`next-themes`）。與菜單主題無關。           |
