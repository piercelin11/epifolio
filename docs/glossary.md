# 詞彙表

文件與討論一律使用這裡的中文詞；程式碼一律使用對應的英文識別字。新增詞彙時保持「一詞一定義」。

| 中文     | 英文識別字      | 定義                                                                                   |
| -------- | --------------- | -------------------------------------------------------------------------------------- |
| 食譜     | `Recipe`        | 一道菜的完整製作資料，包含用量、步驟、參考連結、圖片。功能性資料。                     |
| 菜單     | `Menu`          | 菜單的展示層，由大類、章節與品項組成。                                                 |
| 大類     | `MenuGroup`     | 菜單最上層的分類（例如 Main、Dessert、Drinks），一本菜單書顯示一個大類。               |
| 菜單書   | `MenuBook`      | 首頁的一本書：一個大類加一組菜單主題（可在菜單紙上換），內容是一組紙張堆疊（菜單紙與食譜紙）。資料庫中就是 `MenuGroup`。 |
| 菜單書架 | `MenuShelf`     | 首頁所有菜單書的排列；閱讀模式目前這本置中、兩側露出鄰書，總覽模式所有書縮小排成一列。 |
| 章節     | `Section`       | 菜單中的分區（例如前菜、主菜、甜點）。小標選填，沒有小標時品項直接接在上一個章節後。 |
| 品項     | `MenuItem`      | 菜單上的一道菜。引用一份食譜，並可有自己的顯示名稱、描述、價格。                       |
| 描述片段 | `DescriptionPart` | 品項描述中以 ` · ` 分隔的一段文字，可引用一種食材。                                |
| 用量     | `RecipeIngredient` | 食譜中的一行材料：數量（單值或範圍）、單位、名稱、備註，可引用一種食材。每行有自己的 id，步驟片段與勾選以它引用。 |
| 單位清單 | `units`         | 用量可用的單位（`src/features/recipe/units.ts`）；資料庫存單位 id，合法值只看這份清單。 |
| 用量群組 | `IngredientGroup` | 食譜中一組用量（例如 Pasta、Sauce），小標選填。                                     |
| 食材     | `Ingredient`    | 獨立於食譜的食材資料：名稱、照片、價格、營養（每 100 g）。用量與描述片段以 id 引用。 |
| 食材卡片 | `IngredientCard` | 點食材時從螢幕下方冒出的卡片，顯示該食材的照片、價格與營養。                        |
| 步驟     | `Step`          | 食譜中的一個製作步驟，有順序；重點（`title`，如 Emulsify）選填，文字由步驟片段組成。 |
| 步驟片段 | `StepPart`      | 步驟文字中的一段，可用 `lineId` 引用同一道食譜的一行用量。                           |
| 步驟群組 | `StepGroup`     | 食譜中一組步驟，小標選填；編號跨群組連續。                                             |
| 份數     | `servings`      | 食譜要做幾人份；食譜本身的份數是 `serves`，用量依兩者比例換算。                       |
| 備料進度 | `RecipeProgress` | 某道食譜目前選的份數與已勾選（已備好）的用量；只存在記憶體，重新整理即重設。         |
| 參考連結 | `ReferenceLink` | 食譜的出處或參考資料連結（ref）。                                                      |
| 快速檢視 | `QuickView`     | 清單或搜尋式的精簡呈現。                                                               |
| 菜單主題 | `MenuTheme`     | 一組菜單外觀設定（目前只有顏色，之後可加字型、頁面樣式），每本菜單書套用一組；第一組也是網站預設。 |
| 紙張堆疊 | `PaperStack`    | 首頁疊在一起的兩張紙；位置固定，只有疊放順序會改變。                                   |
| 紙張     | `PaperSheet`    | 紙張堆疊中的一張紙，有底色、材質，可選擇右側打孔。                                     |
| 使用者   | `User`          | 菜單與食譜的擁有者。目前只有一個預設使用者，由 `getCurrentUserId()` 取得。           |
| 編輯卡   | `EditorCard`    | 在書上打開、用來編輯的卡片：菜單編輯卡、匯入卡、食譜編輯卡；由 `EditorLayer` 管理，目前的卡記在網址 `?edit=`。 |
| 菜單編輯卡 | `MenuCard`    | 編輯一本菜單書的書名、章節與品項的打孔卡片。                                   |
| 匯入卡   | `ImportCard`    | 菜單編輯卡的背面，新增品項的起點：Scratch（手填）、Text、Photo、URL（交給 LLM 讀取）。 |
| 食譜匯入 | `recipe-import` | 由 LLM 把文字、照片、PDF 或網頁整理成品項與食譜草稿；只產生草稿，Save 才寫入。 |
| 食材確認卡 | `IngredientReviewCard` | 匯入後決定每行用量對應哪個食材的卡片：已對上的收在最下方，未對上的選 Create new 或 Link to。 |
| 食材比對 | `matchLine` | 用 LLM 給的標準名稱、同義詞與原文寫法，以程式比對食材目錄的名稱與別名，得到每行的狀態與候選。 |
| 估計營養 | `nutritionEstimated` | 食材的營養是 LLM 估計、尚未確認的值。                                   |
| 食譜編輯卡 | `RecipeCard`  | 編輯一份食譜的票券形卡片：名稱、份數、用量、步驟、參考連結。                   |
| 草稿     | `draft`         | 編輯卡上尚未存檔的內容；格式由 zod schema 定義（`MenuBookDraft`、`RecipeDraft`），Save 時一次寫入。 |
| 雙語文字 | `LocalizedText` | 一段可有中英兩種語言的文字 `{ en, zh }`；顯示時用 `localize()` 取值，缺的語言退回另一種。 |
| 介面語言 | `locale`        | 網站目前顯示的語言（`en` / `zh`），由頁首切換按鈕決定、記在 cookie；與編輯卡上「正在編輯哪種語言」不同。 |
| 字典     | `messages`      | 介面文字的中英對照（`src/lib/i18n/messages/`）；元件以 `useMessages()` 取用。 |
| 訊息 key | `ErrorMessage`  | server 端要給使用者看的訊息，以字典 `errors` 區的 key（可帶參數）傳遞，畫面依介面語言顯示。 |
