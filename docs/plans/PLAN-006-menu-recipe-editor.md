# PLAN-006：菜單與食譜編輯卡

## 目標

1. 在書上打開「菜單編輯卡」：改書名、章節與品項的新增、改名、移出菜單、拖曳排序。
2. 新增品項時卡片翻面成「匯入卡」，先只有 Scratch（菜名、描述）可用；按 Next 進入「食譜編輯卡」。
3. 「食譜編輯卡」可編輯食譜名稱、份數、用量（群組、數量、單位、食材、備註）、步驟（群組、重點、內容）、參考連結；可拖曳排序、Tab / Shift+Tab 切換「內容 ↔ 小標」。
4. 每張卡可用 `EN | ZH` 切換正在編輯的語言。
5. 卡片的開啟、翻面、換卡都有銜接動畫；網址跟著目前的卡片改變，上一頁可退回、重新整理可回到同一張卡。

## 非目標

- 刪除整本書、刪除確認、未存檔就取消的提醒（#56）；建立新書（#60）
- 從資料庫刪除食譜：品項只「移出菜單」，食譜留在資料庫（與食譜庫一起處理，#57）
- 食譜庫、把現有食譜加入菜單（#57）
- 品項價格的編輯：之後由食材價格加總（#42）；這次只讓價格可以不填
- 食譜時間、筆記、步驟分鐘數的編輯（#58）
- 圖片上傳（#59）
- TEXT / PHOTO 匯入（LLM，#52）：這次只顯示、停用
- 步驟片段引用用量行的編輯介面（#54）
- 窄螢幕（#10）

## 驗收條件

**入口與網址**

- 閱讀模式下，菜單紙右上角主題按鈕旁有 Edit 按鈕（位置暫定），只有置中那本可操作；點擊後從書上打開菜單編輯卡。
- 開卡時書留在原位、不可操作，書上蓋一層淡遮罩（深淺用 token，可設為 0）。
- 目前的卡片反映在網址：`?edit=menu:<bookId>`、`?edit=new-dish:<sectionId>`、`?edit=recipe:<recipeId>`、`?edit=new-recipe:<sectionId>`。上一頁回到前一張卡或關閉；直接開帶參數的網址或重新整理時，書架照常顯示並打開該卡；參數無效時忽略。
- Esc 等同 Cancel。

**菜單編輯卡**

- 外觀依示意圖：上緣一排打孔、卡紙材質、右上角迴紋針；左上角是書名（大類名稱），其下為章節與品項的清單，底部 Save / Cancel。
- 點書名、章節名、品項名即可直接編輯（inline）；Enter 或離開欄位結束編輯。
- 品項名稱下方有一行較小的品項描述（片段以 ` · ` 分隔），同樣可直接編輯，未輸入時顯示提示字（`Description`）；片段依食材名稱與別名自動對到食材目錄。
- `+ Section` 新增一行空的章節並進入編輯，未輸入時顯示提示字（`Section name`）；`+ Dish` 不新增空行，而是翻面到匯入卡（見下）。
- 滑過或選取品項、章節時左側出現 `−`，點擊即從草稿移除（品項只移出菜單；章節連同其品項移出）。
- 滑過品項時名稱右側出現 `↗`，點擊換到該食譜的編輯卡（見「換卡」）。
- 品項可上下拖曳，也可拖到其他章節；章節可上下拖曳（連同品項）。章節不能變成品項，品項也不能變成章節。不需要拖曳把手：按住移動超過門檻才算拖曳，單純點擊仍是編輯；正在輸入的那一行不能拖。
- 內容超出卡片時可在卡內上下捲動，捲軸樣式依示意圖（右側粗黑條）。
- 所有變更是草稿，按 Save 才一次寫入；Cancel 放棄草稿並關卡。Save 失敗時保留草稿並顯示 toast。

**匯入卡**

- 由菜單編輯卡以垂直中線為軸水平翻面而來；翻回時反向。
- 選項依序為 `Scratch`（預設）、`Text`、`Photo`；`Text`、`Photo` 停用並標示 `Coming soon`，選取時顯示示意圖中的內容但 Next 停用。
- Scratch：`Dish name`（必填）、`Description (optional)`。描述以 ` · ` 分段，片段依食材名稱與別名自動對到食材目錄。
- Next 進入新食譜的編輯卡（見「換卡」），菜名同時作為品項名稱與食譜名稱的初始值；Cancel 翻回菜單編輯卡。

**食譜編輯卡**

- 外觀依示意圖：四角內凹的票券形卡片、卡紙材質；標題是食譜名稱，可直接編輯。
- 份數：`Ingredients` 標題列右側 `− n + servings`，與食譜紙的份數控制相同（範圍依 `src/features/recipe/scaling.ts`）。
- `Ingredients`：用量群組（小標選填）與用量行。用量行有四欄：`Qty`、`Unit`、`Ingredient`、`Note`（選填）；`+ Ingredient` 新增一行，`+ Group` 新增群組。
  - `Qty` 接受 `1`、`1.5`、`1/2`、`80-100`，可留空（如 to taste）；`Unit` 從 `src/features/recipe/units.ts` 選，可留空；`Ingredient` 必填，依名稱與別名自動對到食材目錄。
- `Instructions`：步驟群組（小標選填）與步驟。步驟兩欄：`Highlight (optional)`、`Instruction`；`+ Step`、`+ Group`。
- `References`：`+ URL` 新增一行網址。
- 拖曳排序：用量行可在群組內與群組間移動，群組可整組移動；步驟同理。
- Tab / Shift+Tab：在一行內容上按 Shift+Tab 變成小標（成為新群組，後面的行歸到它底下）；在小標上按 Tab 變成內容（它底下的行併入上一組）。用量行變成小標時，數量、單位、備註捨棄。
- `−` 刪除行或群組；`+` 新增後直接進入編輯並顯示提示字。
- Save 以 zod 驗證後寫入，失敗時標出欄位或顯示 toast；Cancel 放棄。新食譜的 Save 會同時建立食譜與品項（放在發起的章節最後）。
- 存檔後回到菜單編輯卡（從菜單卡來時）或關卡。

**雙語**

- 每張卡右上角有 `EN | ZH`，切換正在編輯的語言；只影響該卡的文字欄位，數量、單位、網址等不分語言的欄位兩邊共用。
- 新內容至少要有一種語言；另一種可留空（畫面依 ADR-0013 退回另一種）。

**透視與動畫**

- 卡片背面的內容（菜單卡的背面是匯入卡，反之亦然）左右鏡像、以低透明度從正面透出；書與菜單不透出。
- 開卡：卡片從書上方冒出；關卡反向。翻面：`rotateY` 180°。菜單卡 → 食譜卡（`↗`）與匯入卡 → 食譜卡（Next）：目前的卡往下收、食譜卡從下方冒出（先依此實作，使用者再調整）。
- 動畫參數集中在一個設定檔；系統減少動態效果時改為直接切換。

**資料**

- `MenuItem.price` 改為選填（migration）；沒有價格時菜單不顯示價格。
- 表單、Server Action（之後的 LLM）共用同一份 zod schema。
- 編輯既有食譜時保留未刪除用量行的 id（步驟片段與勾選以它引用，ADR-0015）。

**素材**

- 新增 `public/stationery/`，放迴紋針（使用者提供，轉成 webp）與既有的長尾夾；`public/textures/` 只放紙張與卡紙材質。

**共通**

- UI 文字英文；只用語意 token；`pnpm typecheck`、`pnpm lint`、`pnpm format:check` 通過；瀏覽器實測依 R4。

## 邊界情況

- 章節或書名清空後 Save：zod 擋下並提示（書名、章節名、品項名、食譜名、用量的 Ingredient 必填，至少一種語言）。
- 移出的品項、章節：資料庫中的食譜保留，只是不再出現在任何菜單（食譜庫完成前看不到）。
- `Qty` 寫成 `abc`、`5-2`（下限大於上限）：欄位標錯，不能存。
- `Unit` 有值但 `Qty` 空白：允許（例如 `tbsp` to taste），照原樣顯示。
- 用量行刪除後，引用它的步驟片段當一般文字（ADR-0015）。
- 匯入卡按 Next 後在食譜卡按 Cancel：不建立任何東西，回到菜單編輯卡。
- 菜單卡有未存的草稿時進入食譜卡並存檔：食譜立即寫入；菜單卡草稿仍保留，需另外按 Save。
- 拖曳到卡片可視範圍外：卡內自動捲動。
- 拖曳時按 Esc：取消這次拖曳。
- 網址帶不存在或不屬於目前使用者的 id：忽略參數，只顯示書架。

## 設計摘要

### 1. 編輯器的狀態與網址

編輯器是書架上的一個狀態機（`closed → menu ⇄ import → recipe`），所有卡片在同一個元件樹內，翻面與換卡由同一處控制動畫。每次換卡以 `history.pushState` 更新 `?edit=`，`popstate` 時同步狀態；不走 Next 的路由換頁，所以書架不會重新掛載。與攔截路由的取捨寫成 ADR。

### 2. 資料流

```mermaid
flowchart LR
    SHELF[MenuShelf] -->|?edit=| EDITOR[EditorLayer 狀態機]
    EDITOR --> MENU[菜單編輯卡] -->|saveMenuBook| SA[Server Actions]
    EDITOR --> IMPORT[匯入卡]
    EDITOR --> RECIPE[食譜編輯卡] -->|saveRecipe / createDish| SA
    SA -->|zod schema（共用）| DB[(SQLite)]
    SA -->|refresh()| SHELF
```

- 編輯卡讀的資料：菜單卡沿用書架已有的 `MenuBook`（需要兩種語言時另以 Server Action 讀取原始雙語資料）；食譜卡開啟時以 Server Action 讀取該食譜的雙語資料。
- 寫入：`saveMenuBook` 以一個 transaction 比對草稿與資料庫，更新、新增、移出章節與品項並重排 `position`；`saveRecipe` 同理處理群組、用量行、步驟、參考連結，保留既有用量行 id。

### 3. 拖曳

用 dnd-kit（選型寫 ADR）：多容器排序，啟動條件為移動距離門檻；章節與品項、群組與行各自是不同層級的 sortable，不能跨層級。「內容 ↔ 小標」只由 Tab / Shift+Tab 改變，拖曳只改順序。

### 4. 外觀

- 兩張卡的材質都與食材卡片相同（`card-stock.webp`）；底色：菜單編輯卡 `#B4B1AD`、食譜編輯卡`#C2B8AE`，文字 `#212121`。這些顏色不隨菜單主題變動，放 `globals.css` 的 `:root` token。遮罩、捲軸、卡片尺寸同樣用 token；票券內凹角用 CSS mask。
- 背面透視：卡片內兩層內容，背面層 `scaleX(-1)` 加低透明度，放在正面內容下、紙張材質上。
- 圖示：`lucide-react`（`ArrowUpRight`）；示意圖中的實心方框 `+` / `−` 以小元件自繪。

## 任務拆解

1. ADR：編輯器用狀態機 + `pushState`（不用攔截路由）；拖曳套件 dnd-kit；品項「移出菜單」不刪食譜；`public/stationery/`
2. 素材與資料：`public/stationery/`（迴紋針、長尾夾）；`MenuItem.price` 選填（migration）與菜單不顯示空價格
3. 共用 zod schema（菜單、食譜、Scratch、數量解析、雙語）與 Server Actions（讀取雙語資料、`saveMenuBook`、`saveRecipe`、`createDish`）
4. 編輯器外殼：Edit 按鈕、遮罩、卡片元件（打孔卡、票券卡、迴紋針、捲軸）、狀態機與網址同步、開關動畫、`EN | ZH`
5. 菜單編輯卡：inline 編輯、新增、移出、拖曳排序、`↗`
6. 匯入卡與翻面：Scratch 表單、停用的 Text / Photo、背面透視
7. 食譜編輯卡：各區塊、四欄用量、Tab / Shift+Tab、拖曳、存檔
8. 卡片之間的轉場與減少動態效果
9. 文件：功能頁（新增「編輯卡」）、glossary、architecture、STATUS
